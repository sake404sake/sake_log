🌐 Google ドライブ・クラウド自動同期

各自のGoogleアカウントでログインすると、お持ちのGoogleドライブ上の安全な領域に、お酒のデータと圧縮写真が自動保存されます。スマホやPCなど複数の端末で同じGoogleアカウントを使ってリアルタイムに自動同期が可能です。

🔌 ステータス: 未ログイン（ローカル保存動作中）

※Googleログインにはご自身のGoogle Cloudで発行した無料の「OAuthクライアントID」が必要です。下のガイドから簡単に発行・設定できます。

❓ Googleログインの作成手順はこちら
  1. 「Google Cloud Console」にアクセスして無料プロジェクトを作成。
  2. APIライブラリで「Google Drive API」を有効化。
  3. 「OAuth 同意画面」を「外部」で作成。スコープに .../auth/drive.file を追加。
  4. 「認証情報」から「OAuth クライアント ID（ウェブ アプリケーション）」を作成。
  5. 「承認済みの JavaScript 生成元」に、ご自身のGitHub Pagesのアドレス（例: https://username.github.io）を追加。
  6. 発行されたクライアントIDをコピーし、上の入力欄に貼り付ければ準備完了です！
🔑 Gemini AIソムリエの有効化

APIキーは、サーバーには一切送信されず、お使いの端末（ブラウザ）にのみ安全に保存されます。また、一度分析した結果はログデータの中に自動保存されるため、無駄にAPIキーを何度も消費することはありません。
